# wizardEPIC — «Арена стихий» (UE 5.8, копия по мотивам рилса Crimson Desert Avatar-build)

## Контекст
- **Референс** (изучен покадрово): яркая стилизованная долина, стихийная магия — огненный взрыв с обломками (~6с), пылевой удар земли (~18с), грозовой шторм с молниями и искрами (~24с), полная разрушаемость деревьев/камней/строений, ловкий траверс.
- **Движок — Unreal Engine 5.8.4** (уже установлен, `C:\Program Files\Epic Games\UE_5.8`): Niagara = стандарт VFX для заклинаний (ваши Fab-паки — родные для него), Chaos Destruction = лучшая разрушаемость на рынке, Lumen = стильная картинка «из коробки». Тулчейн проверен: VS2022 BuildTools (MSVC 14.44) + WinSDK 10.0.26100 + UBT.
- **Fab-паки** на диске не найдены (VaultCache пуст) → проект делаю **самодостаточным**: собственные стилизованные эффекты + data-driven слоты, в которые паки подставляются позже за пару кликов (инструкция в README).

## Игра (v1 — лёгкая, стильная)
Third-person песочница со счётом разрушений, арена — зелёная долина как в рилсе:
- **4 заклинания** (выбор 1–4, каст ЛКМ):
  1. 🔥 **Пепельный сфер** — снаряд с трейлом, взрыв, радиальный импульс, обломки разлетаются
  2. 🪨 **Земляной клин** (Earthen Wedge из рилса) — ряд каменных столбов вырастает из земли по направлению прицела, массовый импульс
  3. 🌪 **Эхо бури** (Storm's Echo из рилса) — пронзающий конус ветра: расшатывает и рушит лёгкие конструкции, швыряет обломки
  4. ⚡ **Грозовой жезл** — мгновенный удар молнии в точку прицела, искры, шаттер камней
- **Траверс**: спринт + рывок (dash), прыжок — ловкость как в рилсе
- **Всё разрушаемо**: каменные стены, башня-руина, деревья, амфоры — Chaos Geometry Collections; мишени-кристаллы дают очки; **R** — восстановить арену
- **Стиль**: Lumen GI, объёмные облака, сочная палитра, блум на заклинаниях, лёгкая зернистость, минимальный HUD (слоты заклинаний с откатами + счётчик разрушений + подсказки)
- Без ИИ-врагов в v1 — чистый шоукейс заклинаний и разрушаемости

## Реализация (всё в `C:\Users\user\Desktop\wizardEPIC`)
**1. Скелет проекта**: `wizardEPIC.uproject` (5.8, плагины: EnhancedInput, Niagara, ChaosSolverPlugin, GeometryCollectionPlugin), `Config/DefaultEngine.ini` (Lumen, Chaos, классы GameMode/-character), `DefaultInput.ini`.

**2. C++-модуль `Source/WizardEPIC/`** (~12 файлов):
- `WizardEPICCharacter` — третье лицо, Enhanced Input (движение/камера/рывок/каст/выбор/сброс)
- `SpellDataAsset` (UDataAsset) — тип заклинания, слоты Niagara-FX (каст/полёт/удар), урон, радиус, импульс, откат → **сюда вставляются ваши Fab-паки**
- `SpellCasterComponent` — откаты, диспетчеризация каста
- `SpellProjectile` (огонь), `EarthPillarSpawner` (земля), `WindGust` (воздух), `LightningStrike` (молния) — все бьют через `ApplyRadialDamage` + Chaos-импульсы
- `DestructionScoreComponent` — ловит Chaos-события разрушения → очки, регенерация арены
- `WizardHUD` (UMG из C++ — не нужны авторские виджеты), `WizardGameMode`

**3. Генерация контента — `ContentForge.py`** (Editor-Python, запускается автоматически): копирует манекен из движкового шаблона TP_ThirdPerson (на диске, проверено) с анимациями; строит стилизованные материалы (трава/камень/дерево) и простые меши арены; создаёт **Geometry Collections** с(fracture для разрушаемых строений (при недоступности Python-API — надёжный fallback: кластеры физических обломков, тот же путь импульсов); делает плейсхолдер Niagara-эффекты 4 стихий (если API автора Niagara не позволит — стильные материальные эффекты+свет, Fab-паки заменят их в тех же слотах); собирает уровень `L_Arena` (ландшафт, строения, свет, облака, пост-процесс, GameMode).

**4. Сборка/проверка**: UBT-компиляция до чистого результата → запуск редактора с `-ExecutePythonScript=ContentForge.py` → проверка созданных ассетов → запуск `-game` с проверкой лога и скриншотом арены.

**5. `README_RU.md`**: запуск, управление, точные слоты для подключения ваших Fab-паков заклинаний.

## Проверка (end-to-end)
1. `Build.bat WizardEPICEditor Win64 Development` — компиляция без ошибок
2. Прогон ContentForge в редакторе — ассеты созданы и сохранены
3. Запуск игры в окне — лог без критических ошибок, скриншот арены для визуальной проверки
4. Ручной чек-лист вам в README: каст всех 4 стихий, разрушение стены/башни, счёт очков, сброс арены
